# 画像の置き場

ファイルを置くだけで、画面に反映されます（コードの変更は不要）。ファイルが無い間は、色のグラデーションで代わりに表示されます。

| ファイル | 使われる場所 | 目安 |
|---|---|---|
| `hero/hero-1.jpg` 〜 `hero/hero-5.jpg` | トップの全面スライド（5枚） | 横長 2400×1350px 以上、1枚 400KB 以下。文字が重なるので、中央に被写体がない写真が向く |
| `logo-mark.png`（または `.svg`） | トップの導入部の大きなロゴ | 正方形 600×600px 以上、背景は透過 |

- 写真は、ご自身で撮影したもの、または利用条件を確認した素材だけを使う（参考サイトの写真は使わない）。
- 人が写る写真は、本人の掲載承諾を取ってから。
