# 画像の置き場

ファイルを置くだけで、画面に反映されます。ファイルが無い間は、色のグラデーションと文字のロゴで代わりに表示されます。

| ファイル | 使われる場所 | 目安 |
|---|---|---|
| `hero/hero-1.jpg` 〜 `hero/hero-5.jpg` | トップの全面スライド（5枚） | 横長 16:9、1600px 以上、1枚 400KB 以下。文字が重なるので、全体を暗く（55%）している |
| `logo-mark.png` | ロゴの元画像（背景が透明な PNG、または白い背景に濃い緑の線画。配置済み） | 置き換えたら `python3 scripts/make-logo.py` で下の2つを作る |
| `logo-dark.png` | トップの導入部（白い地の上） | `make-logo.py` が作る透過 PNG（余白は切り落とす） |
| `logo-white.png` | ヘッダー（濃い緑の帯・写真の上） | `make-logo.py` が作る透過 PNG（白の線画） |

- 現在のスライド5枚（駅のホーム・病院の入口・商店街・空港・公園のベンチ）は、利用者が ChatGPT で作成した画像。実在の利用者・スタッフの写真ではないので、「お客様の写真」「実際の様子」などと読める説明を付けない。
- 実際に撮影した写真や、利用条件を確認した素材に差し替える場合も、同じファイル名で置く。
- 人が写る写真は、本人の掲載承諾を取ってから使う。

## ご利用例の写真（`cases/<スラッグ>.jpg`）

`public/images/cases/<スラッグ>.jpg` を置くと、一覧のカードと詳細ページに出ます。無い間はジャンル色の面と題名で代わりに表示されます。スラッグは `src/content/cases/` のファイル名です。

| スラッグ | 場面 | 写真の案（人物は後ろ姿・遠景・横顔で、顔を特定させない） |
|---|---|---|
| `tsuin` | 通院の付き添い | 病院の入口へ向かう、付き添う人と高齢の方の後ろ姿 |
| `shoshin-kensa` | 初めての病院・検査の日 | 広い病院のロビーで、案内板を一緒に見上げる2人 |
| `kaimono` | お買い物 | スーパーの入口。付き添う人が買い物かごを持ち、高齢の方と並んで歩く |

| `yakusho-ginko` | 区役所・銀行の窓口 | 窓口の待合で、並んで座って順番を待つ2人 |
| `nichigaeri` | 日帰りのお出かけ | 公園の遊歩道を、ゆっくり並んで歩く2人の後ろ姿 |
| `ryokou-kokunai` | 国内旅行 | 温泉街の石畳を、荷物を持って歩く2人 |

- 横長 16:9、1600×900px 以上、1枚 300KB 以下（JPEG）。文字は重ねないので暗くしない。
- 生成AIの画像でも、実在の利用者・スタッフの写真と読める説明は付けない。ページには「画像はイメージです」と出る。
- 生成するときの指示の例: 「日本の街で、付き添う人（40代）と高齢の方（80代）が並んで歩く後ろ姿。自然光、落ち着いた色合い、写真風、文字なし、16:9」。

## トップのスライド5枚のストーリー（2026-10-11 の分析）

見た人に「この人たちなら、うちの親（自分）を安心して任せられる」と想像してもらう順に並べる。人物は後ろ姿・遠景・手元のみ（顔を特定させない）。5枚のうち4枚は「付き添う人と本人の2人」、1枚は景色の余白にする。光は朝〜昼のやわらかい自然光（夕暮れの暗い写真を増やさない）。

| 順 | ファイル | 見せたいこと（受ける印象） | いまの写真 | 変更の案 |
|---|---|---|---|---|
| 1 | `hero-1.jpg` | そばにいてくれる（安心） | 駅のホームを歩く2人の後ろ姿（杖）。主役が写る | **据え置き**（朝〜昼の光の差し替え版があれば替える） |
| 2 | `hero-2.jpg` | 通院も任せられる（信頼） | 病院の入口。人は遠景の1人だけ | 病院の入口へ向かう2人（本人に手を添える付き添い）。朝の光 |
| 3 | `hero-3.jpg` | 日常の買い物が楽しい（日常） | 商店街を1人で歩く後ろ姿 | 商店街で買い物袋を持ち、並んで歩く2人の横顔か後ろ姿。笑っている雰囲気 |
| 4 | `hero-4.jpg` | 旅に出られる（憧れ） | 空港のラウンジに1人で座る後ろ姿 | 空港や旅先で、窓の外の景色を2人で眺める後ろ姿。明るい空 |
| 5 | `hero-5.jpg` | まずは話してみよう（相談） | 公園のベンチ（無人） | 公園のベンチに2人が並んで座り、話している後ろ姿（相談のイメージ） |

- 生成の指示の例（共通）: 「日本の街。付き添う人（40代）と高齢の方（80代）が並ぶ後ろ姿または横顔。自然光、朝〜昼、落ち着いた温かい色合い、写真風、文字なし、16:9、人物の顔をはっきり写さない」。
- 差し替えたら `src/components/Hero.astro` の `pos`（スマホで残す横位置）を見直し、1440/390px で人物が見えることを確かめる。コピーの文言も写真に合わせて見直す（2枚目「通院も、お買い物も」→通院の写真、3枚目の「ひとりでは心配…」は買い物の写真に合わせて「お買い物も、楽しく」など）。
